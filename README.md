# TeknoKıyas

Teknoloji ürünlerini teknik özellikleriyle kıyaslayan, kullanıcı oyu alan ve küresel puan gösteren bir karşılaştırma platformu.

Katalogda 4.779 model vardır. 20 model resmi üretici ölçüleri ve fotoğraflarıyla durur. Diğerleri Wikidata / Wikipedia / Wikimedia Commons kayıtlarıyla eşleştirilir; Epey ve GSMArena canlı sayfaları bot koruması nedeniyle tarayıcıdan çekilemedi.

## Web

```bash
npm run dev
```

Tarayıcıda [http://127.0.0.1:3000](http://127.0.0.1:3000) adresini açın.

## Flutter (mobil)

Tarayıcıda görüntüle: [https://ruguikayrit.github.io/cepkiyas/](https://ruguikayrit.github.io/cepkiyas/)

Kaynak: [mobile/](https://github.com/ruguikayrit/cepkiyas/tree/main/mobile)

cd mobile
